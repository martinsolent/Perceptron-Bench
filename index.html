    How it works

    • Each switch is an input xi, either 0 or 1. Each knob is a weight wi between −30 and +30.
    • The meter shows Σ wᵢxᵢ + b. Only knobs on switches that are on count. Needle right means the first class; needle left means the second.
    • Learning rule: show it an example. If the needle swings the wrong way, add step × target to every weight whose switch is on, and to the bias (target is +1 or −1). Repeat until a whole pass has no mistakes.
    • The perceptron convergence theorem says this always ends if a straight line (a hyperplane) can separate the two classes. XOR can't be separated that way, so it never settles. Minsky and Papert made this limitation famous in 1969.
