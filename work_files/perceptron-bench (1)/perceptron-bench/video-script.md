# Perceptron Bench: explainer video script

**Length:** 1:11 · **Voice:** narrated (British English) · **Format:** 1920×1080, 30 fps

A short animated introduction to the perceptron: what it is, how it decides, how it learns, and why it led to modern AI.

---

## Full narration

> What is a perceptron? It's a 1958 idea that sits at the heart of modern AI.
>
> It starts with an input. Here, a tiny four-by-four picture. Each pixel is either on, a one, or off, a zero.
>
> Every pixel gets a weight, set by its own knob. Positive weights push the answer towards X. Negative weights push it towards O.
>
> The perceptron adds up the weights of the pixels that are lit. The total is plus twenty. Positive, so it answers X.
>
> So how does it learn? We start with every knob at zero. Show it an X. It gets it wrong, so we nudge the lit knobs towards X. Now an O. Wrong again, so we nudge them towards O. Try again, and now both are right. It's learned!
>
> But a single perceptron can only draw one straight line, so it can't solve problems like this one, called XOR. Stack lots of them in layers, though, and you get the neural networks behind modern AI.
>
> Try it yourself, with Perceptron Bench.
